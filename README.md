# Gamer Arena Reservation System - Akron Stadium

A modern, intuitive, and fully responsive web platform designed to revolutionize the experience of booking the Gamer Arena located in the Akron Stadium. From the first click, users are greeted with a sleek gamer-themed interface aligned with the brand’s identity, smooth transitions, and perfectly organized sections.

## Key Features:
- Seamless Navigation: A dynamic side menu provides quick access to reservations, news, rules, and user profiles. The menu adapts based on login status, showing the user’s name and profile picture for a personalized experience.
- Smart Reservation System: Fully visual booking form with real-time validations, preventing schedule conflicts and guiding users step by step.
- User Profile Management: View and edit personal data, update profile pictures, and track past and upcoming reservations.
- Administrator Dashboard: Access user stats, active sessions, reservation counts, and demographic data through interactive visual dashboards.
- Administrator Upgrades: Change any information at anytime about the prices, games available, comments, among others.
- Automated Email Notifications: Booking confirmations are sent instantly to users’ inboxes for trust and transparency.
